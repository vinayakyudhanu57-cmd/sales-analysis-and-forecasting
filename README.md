# Sales Analysis and Forecasting

A complete, beginner-friendly retail analytics and time-series forecasting application built with **Base R (4.6.1)**, **ggplot2**, and a clean, **minimal light-theme web dashboard**.

---

## 1. Project Overview

This project provides an end-to-end commercial analytics pipeline for small business sales performance. It processes 36 months of transaction records, examines seasonal trends, ranks product revenue contributions, forecasts total revenue for the next three months with 95% prediction intervals, and presents actionable business recommendations through a clean, light-theme web interface.

> **Note on Data & Forecasts:** The dataset is synthetic demo data representing realistic retail transactions. Projections are model-based planning estimates calculated using Holt-Winters Exponential Smoothing; they do not guarantee future revenue. GitHub Pages serves pre-computed outputs generated by R.

---

## 2. Main Features

- **Data Validation & Hygiene:** Enforces schema structure, parses `YYYY-MM-DD` dates, and validates positive quantities and unit prices without third-party dependencies.
- **Mathematical Reconciliation:** Exact zero-discrepancy reconciliation between transaction rows, monthly summaries, and product totals ($157,534.20 total revenue across 5,027 units).
- **Time-Series Forecasting:** Built-in Holt-Winters Additive Exponential Smoothing (with chronological holdout testing: 7.20% MAPE) providing 3-month projections and 95% prediction bounds.
- **Pure Base R JSON Serialization:** Custom recursive JSON engine exporting valid payloads (`dashboard_data.json`, `business_insights.json`) with zero external package dependencies.
- **Analytical Charts:** High-resolution visualizations (`monthly_trend.png`, `product_comparison.png`, `revenue_forecast.png`) created with `ggplot2`.
- **Minimal Light Web Dashboard:** Zero-dependency static frontend (`index.html`, `style.css`, `script.js`) featuring interactive SVG revenue curves, product progress bars, forecast cards, and strategic insight callouts.

## 5. Prerequisites

- **R Environment:** R 4.0 or higher (Tested with R 4.6.1).
- **R Packages:** `ggplot2` (optional for chart rendering; Base R fallback is included).
- **Web Browser:** Any modern browser (Google Chrome, Microsoft Edge, Firefox, Safari).
- **Local Web Server:** Python 3 (`python -m http.server`) or Node.js (`npx serve`) for local viewing.

---

## 6. How to Run the R Analysis

Open a terminal (PowerShell or Bash) in the project directory:

```powershell
# Run the complete analysis pipeline
& 'C:\Program Files\R\R-4.6.1\bin\Rscript.exe' R/main.R
```

*Or if R is in your PATH:*

```bash
Rscript R/main.R
```

All 5 output files in `output/` and all 3 visual charts in `docs/charts/` will be generated immediately.

---

## 7. How to Start the Local Website

Because modern browsers restrict JavaScript `fetch()` on direct `file://` URIs, serve the project using a simple local HTTP server:

```powershell
# Using Python
python -m http.server 8000
```

Open your browser at: `http://localhost:8000`
